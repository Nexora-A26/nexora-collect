# Nexora Collect — نكسورا للتحصيل

برنامج سطح مكتب عربي بالكامل لإدارة المندوبين والعملاء والمبالغ المستحقة والتحصيلات والعمولات والأرصدة والتقارير.

## التقنية

- React 18
- Vite
- Electron
- TypeScript
- SQLite محلية عبر SQL.js
- Excel عبر SheetJS
- PDF عربي عبر محرك الطباعة الخاص بـ Chromium داخل Electron

## لا توجد بيانات تجريبية

قاعدة البيانات تبدأ فارغة بالكامل. عند أول تشغيل تظهر صفحة إنشاء مدير النظام. بعد إنشاء المدير تصبح شاشة تسجيل الدخول هي الصفحة الأولى.

## المستخدمون والصلاحيات

الأدوار المتاحة:

- مدير النظام
- مستخدم
- مشاهد

يستطيع المدير تحديد صلاحيات كل مستخدم بصورة مستقلة لكل صفحة:

- عرض
- إضافة
- تعديل
- حذف
- تصدير

المشاهد لا يستطيع الإضافة أو التعديل أو الحذف حتى إذا تم تحديدها خطأً، لأن المنع مطبق أيضاً داخل طبقة Electron وقاعدة البيانات وليس في الواجهة فقط.

## الصفحات

- تسجيل الدخول وإعداد المدير لأول مرة
- لوحة التحكم
- المندوبون
- العملاء ونقل العميل بين المندوبين
- المبالغ المستحقة
- عمليات القبض والدفعات الجزئية
- حساب عمولة المندوب وصافي الإدارة
- تسليمات المندوبين
- أرصدة العملاء والمندوبين
- تقارير PDF وExcel
- المستخدمون والصلاحيات
- سجل العمليات
- إعدادات المؤسسة والعملة
- النسخ الاحتياطي والاستعادة

## العملة

العملة الافتراضية هي الدينار العراقي:

- الاسم: الدينار العراقي
- الكود: IQD
- الرمز: د.ع
- المنازل العشرية: 0

يمكن للمدير تغيير اسم العملة والكود والرمز ومكان الرمز والمنازل العشرية والفواصل. تغيير العملة يغيّر طريقة العرض فقط ولا يحوّل الأرقام المحفوظة تلقائياً.

## التشغيل على Windows

1. ثبّت Node.js إصدار 20 أو 22 LTS.
2. فك ضغط المشروع في مسار بسيط مثل `C:\NexoraCollect`.
3. شغّل `RUN_DEV_WINDOWS.bat` للتطوير.
4. عند أول تشغيل أنشئ حساب مدير النظام.

أوامر بديلة:

```bash
npm install
npm run dev
```

## الاختبار

شغّل:

```bash
npm run verify
```

وهو ينفذ:

1. فحص TypeScript.
2. بناء واجهة Vite.
3. اختبار تشغيل Electron وقاعدة البيانات مع خروج تلقائي.

## إنشاء Setup.exe ونسخة Portable

شغّل:

`BUILD_INSTALLER_WINDOWS.bat`

أو:

```bash
npm run dist:win
```

ستجد الملفات داخل مجلد `release`.

## مكان البيانات

تُحفظ قاعدة البيانات داخل مجلد بيانات التطبيق الخاص بالمستخدم تحت اسم:

`data/nexora-collect.sqlite`

استخدم صفحة الإعدادات لإنشاء النسخ الاحتياطية واستعادتها بدلاً من تعديل الملف يدوياً.

## قواعد مالية مطبقة

- لا يمكن قبض مبلغ أكبر من المتبقي.
- تدعم الدفعات الجزئية.
- العمولة = المبلغ المقبوض × النسبة ÷ 100.
- صافي الإدارة = المقبوض - العمولة.
- رصيد المندوب = صافي التحصيلات - التسليمات.
- تعديل أو إلغاء القبض يعيد حساب الفاتورة والرصيد تلقائياً.
- لا يُحذف مندوب أو عميل لديه سجل مالي؛ يتم إيقافه للحفاظ على التاريخ.
- نقل العميل لا يغيّر العمليات القديمة.
- جميع العمليات الحساسة مسجلة في سجل التدقيق.

## إصلاح بناء Windows في الإصدار 1.0.1

تم ضبط بناء Windows ليكون **Unsigned** افتراضياً، مع تعطيل `signAndEditExecutable`. يمنع ذلك تنزيل وتشغيل حزمة `winCodeSign` التي قد تفشل على Windows برسالة تفيد بعدم امتلاك صلاحية إنشاء symbolic link.

لبناء النسخة:

```bat
BUILD_INSTALLER_WINDOWS.bat
```

لا يلزم تشغيل الملف كمسؤول. سيُنشئ البناء ملفات المثبّت والنسخة المحمولة داخل مجلد `release`.

ملاحظة: بما أن التطبيق غير موقّع رقمياً، قد يعرض Windows SmartScreen تنبيهاً عند تشغيله على جهاز آخر. التوقيع الرقمي التجاري يمكن إضافته لاحقاً عند توفر شهادة Code Signing.
